# TREASURE HUNT · Pylli për 17

Live: https://elivula.github.io/treasure-hunt/

A treasure hunt for children at BEAR SANCTUARY Prishtina. The site opens on a passcode page; the page
contents and every document in `files/` are encrypted (AES-256-GCM, key derived from the passcode with
PBKDF2-SHA256) and are decrypted in the visitor's browser. Ask the project team for the passcode.

Generated by `docs/build-web.py` in the project repo (pylli-per-17); don't edit by hand.
